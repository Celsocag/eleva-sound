# 🔊 ELEVA // ACOUSTIC AMPLIFIER

> **Aumente o som além dos 100%. Sem criar conta. Sem anúncios. Direto ao ponto.**

ELEVA é um amplificador acústico minimalista de alta precisão (high-ticket/monocromático) com motor DSP em tempo real e proteção ativa contra distorção harmônica.

---

## ⚡ Características Principais

* **Sem Cadastro / Sem Login**: Abra o app e use instantaneamente.
* **100% Sem Propagandas**: Interface limpa, silenciosa e focada exclusivamente na experiência de áudio.
* **Potência além dos 100% (até 300%)**: Ganho acústico digital avançado.
* **Protetor Ativo contra Distorção**: Compressor dinâmico (*Limiter*) com ataque de 3ms que previne cortes (*clipping*) e protege os alto-falantes do aparelho.
* **100% à Prova de Usuário**: Calibrações e impedimentos de sistema (como travas de decibéis do Android ou segurança de fone do iOS) são tratados por baixo dos panos com assistência sob demanda.

---

## 🚀 Como testar localmente (Preview no Navegador)

```bash
npm install
npm run dev
```

Abra [http://localhost:5173/](http://localhost:5173/) no seu navegador.
